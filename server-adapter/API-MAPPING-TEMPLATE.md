# ACG-Faka 管理接口核对清单

以下都是待核对项，不表示项目中已经存在对应路由。

| 模块 | 必须核对的真实能力 |
|---|---|
| 登录 | Session/cookie、CSRF、登录保护、二步验证 |
| 插件 | 插件列表、启停方法、生命周期、缓存刷新 |
| 订单 | 分页/筛选/详情/状态变更权限 |
| 商品与卡密 | 商品 CRUD、库存、卡密发放/脱敏/导出权限 |
| 用户 | 查询、封禁、权限修改的角色限制 |
| 网站设置 | 字段白名单、路径安全、保存后缓存处理 |
| 日志 | 只读、行数上限、敏感信息脱敏、禁止任意路径 |
| 公告与版本 | 由受信任管理员配置、审计记录、版本策略缓存 |

不要为方便而提供任意 SQL、任意文件读写、任意 PHP 执行或通用 Shell API。
